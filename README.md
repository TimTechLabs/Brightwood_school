# 🏫 Brightwood School Management Portal

A full-stack Web Application built with Django and modern responsive HTML5/CSS3. Engineered to manage student records, grade tracking, and administrative workflows with seamless navigation.

🌐 **Live Demo:** [https://brightwood-school-1.onrender.com](https://brightwood-school-1.onrender.com)

### ✨ Key Features
* **Responsive Landing Page:** Fully optimized across mobile, tablet, and desktop viewports.
* **Authentication & Access Control:** Secure portal entry for students and administrators.
* **Student Record Directory:** Seamless administrative search, lookup, and updates.
* **Modern UI:** Built with custom CSS flexbox/grid layouts and clean visual scaffolding.

---

### 🛠️ Tech Stack
* **Backend:** Python, Django
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
* **Database:** SQLite / PostgreSQL
* **Deployment:** Render
